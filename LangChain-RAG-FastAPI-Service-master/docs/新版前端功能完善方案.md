# 新版前端功能完善方案

## 一、项目结构建议

### 当前结构问题

新版前端 (`src/`) 位于项目根目录，与 `LangChain-RAG-FastAPI-Service-master/` 同级。虽然技术栈不同（Vue 3 + Arco Design + TypeScript vs Vue 3 + Vant + JavaScript），但根目录的 `src/` 容易让人误解为后端代码的一部分。

### 建议方案

将 `src/` 重命名为 `front-v2/`，使其与旧版前端 (`LangChain-RAG-FastAPI-Service-master/front`) 形成清晰的对应关系：

```
RAG-Note/
├── LangChain-RAG-FastAPI-Service-master/
│   ├── backend-java/          # Java 后端
│   └── front/                 # 旧版前端 (Vant)
├── front-v2/                  # 新版前端 (Arco Design) ← 建议重命名
│   ├── src/
│   ├── vite.config.ts
│   ├── package.json
│   └── ...
└── docs/
```

> 如果不想移动，保持 `src/` 也可以，但建议在根目录 README 中说明。

## 三、Token 存储统一

**问题：** 旧版使用 `jwt_token` 作为 localStorage key，新版使用 `token`。这会导致两个前端的登录状态不互通。

**建议：** 统一为 `jwt_token`，修改以下文件：
- `src/store/user.ts` - `localStorage.getItem('token')` → `localStorage.getItem('jwt_token')`
- `src/api/index.ts` - 拦截器中的 token 读取
- `src/router/index.ts` - 路由守卫中的 token 检查
