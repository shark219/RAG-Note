# AI Agent 功能测试用例

## 测试前准备

1. 启动后端服务
2. 获取 JWT Token（登录接口）
3. 上传几篇测试文档到知识库
4. 创建几篇测试笔记

```bash
# 登录获取 Token
TOKEN=$(curl -s -X POST http://localhost:8080/user/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}' | jq -r '.data.token')

# 通用请求函数
ask() {
  curl -s -N -X POST http://localhost:8080/chat/agent/query/stream \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d "{\"query\":\"$1\"}" 2>/dev/null
}
```

## 一、意图识别测试

### 1.1 模糊提问 → 应触发澄清
```bash
ask "帮我学习AI"
```
**预期**: 返回澄清方向选项（3-4 个具体方向），或直接给出宽泛回答

### 1.2 清晰查询 → 直接执行
```bash
ask "搜索我笔记里关于 BM25 的内容"
```
**预期**: 调用 searchNotes 工具，返回相关笔记列表

### 1.3 多意图混合 → 应拆分处理
```bash
ask "帮我搜索笔记里关于机器学习的内容，再从知识库里找相关文档，最后统计一下我有多少笔记"
```
**预期**: 调用 searchNotes + ragSummary + getNoteStats 三个工具

### 1.4 专业术语 → 直接回答
```bash
ask "什么是 Transformer 的自注意力机制？"
```
**预期**: 直接用通用知识回答，不调用工具

### 1.5 闲聊 → 不调工具
```bash
ask "你好，今天天气怎么样？"
```
**预期**: 直接回复，不调用任何工具

### 1.6 歧义问句 → 应澄清或合理推断
```bash
ask "帮我看看"
```
**预期**: 要么返回澄清选项，要么推断为查看笔记列表

## 二、工具调用链路测试

### 2.1 单工具调用 — 笔记搜索
```bash
ask "搜索我的笔记里有没有关于 RAG 的内容"
```
**预期**: 调用 searchNotes(query="RAG")
**验证**: 返回结果中应包含相关笔记标题

### 2.2 单工具调用 — 知识库检索
```bash
ask "知识库里是怎么定义 BM25 算法的？"
```
**预期**: 调用 ragSummary(query="BM25算法定义")
**验证**: 返回结果应基于知识库文档

### 2.3 单工具调用 — 创建笔记
```bash
ask "帮我创建一篇笔记，标题是'学习记录'，内容是'今天学习了 RAG 原理'"
```
**预期**: 调用 createNote(title="学习记录", content="今天学习了 RAG 原理")
**验证**: 笔记创建成功

### 2.4 多工具串联 — 搜索后创建
```bash
ask "帮我搜索知识库里关于 Transformer 的内容，然后把搜索结果整理成一篇新笔记"
```
**预期**: 先调 ragSummary → 再调 createNote
**验证**: 两个工具按顺序调用，新笔记内容基于检索结果

### 2.5 多工具并行 — 同时查询
```bash
ask "我的笔记有几篇？知识库里有多少文档？"
```
**预期**: 调用 getNoteStats + ragSummary（可能并行）
**验证**: 返回两部分信息

### 2.6 工具参数填充 — 部分参数
```bash
ask "帮我创建一篇笔记"
```
**预期**: Agent 应该追问标题和内容，或用默认值创建
**验证**: 不应因缺少参数而崩溃

### 2.7 工具调用失败 — 不存在的笔记
```bash
ask "帮我找到 ID 为 99999 的笔记"
```
**预期**: 工具返回"未找到"，Agent 用自然语言告知用户
**验证**: 不应返回错误堆栈

## 三、任务拆解与规划测试

### 3.1 复杂任务 — 自动拆分
```bash
ask "帮我整理一下我的 AI 学习笔记，总结知识库里的内容，再看看今天有什么要复习的"
```
**预期**: Supervisor 拆分为 3 个子任务并行执行
**验证**: 思考过程中应显示"规划→研究→写作"阶段

### 3.2 简单任务 — 不拆分
```bash
ask "搜索笔记 BM25"
```
**预期**: 走单 Agent 流程，不触发 Supervisor 拆分
**验证**: 思考过程中不应出现"规划"阶段

### 3.3 子任务独立性
```bash
ask "帮我对比笔记里的 RAG 内容和知识库里的 RAG 内容有什么区别"
```
**预期**: 拆分为两个独立检索子任务 + 一个对比写作任务
**验证**: 两个检索应并行执行

### 3.4 任务终止判断
```bash
ask "创建一篇空笔记"
```
**预期**: Agent 直接创建，不需要多轮对话
**验证**: 一次工具调用后返回结果

## 四、记忆管理测试

### 4.1 短期记忆 — 上下文连贯
```bash
# 第一轮
ask "什么是 RAG？"
# 第二轮（不提 RAG）
ask "它有什么优缺点？"
```
**预期**: 第二轮回答应理解"它"指的是 RAG
**验证**: 回答内容与 RAG 相关

### 4.2 多轮记忆 — 前文引用
```bash
# 第一轮
ask "帮我搜索笔记里关于机器学习的内容"
# 第二轮
ask "刚才搜索到的笔记有几篇？"
```
**预期**: Agent 应理解"刚才搜索到的笔记"指上一轮结果
**验证**: 回答引用前文信息

### 4.3 话题切换 — 记忆隔离
```bash
# 第一轮
ask "什么是 BM25？"
# 第二轮（切换话题）
ask "帮我创建一篇笔记"
# 第三轮
ask "继续刚才的话题"
```
**预期**: "继续"应回到 BM25 话题，而非创建笔记
**验证**: 回答与 BM25 相关

### 4.4 长对话 — 上下文压缩
```bash
# 连续问 15+ 个问题，然后问一个需要早期信息的问题
ask "我第一个问题问的是什么？"
```
**预期**: 即使触发了上下文压缩，仍能回忆早期关键信息
**验证**: 回答正确或给出合理近似

### 4.5 记忆溢出 — 超长对话
```bash
# 发送 30+ 条消息后
ask "总结一下我们刚才讨论的所有话题"
```
**预期**: 不应因上下文过长而崩溃
**验证**: 给出合理的摘要

## 五、RAG 质量测试

### 5.1 检索相关性
```bash
ask "知识库里关于向量检索的原理是什么？"
```
**预期**: 检索到的文档与向量检索相关
**验证**: 回答基于实际文档内容，非编造

### 5.2 检索审查 — 不相关文档
```bash
ask "知识库里有没有关于量子计算的内容？"
```
**预期**: 如果知识库没有相关内容，明确告知
**验证**: 不编造不存在的信息

### 5.3 回答忠实度
```bash
ask "根据知识库，BM25 的公式是什么？"
```
**预期**: 回答应忠实于文档内容
**验证**: 公式与文档一致

### 5.4 质量重试
```bash
ask "详细总结知识库里所有关于 AI 的内容"
```
**预期**: 如果第一次回答质量不够，应自动重试
**验证**: 思考过程中可能出现"审查"阶段

## 六、边界情况测试

### 6.1 空输入
```bash
ask ""
```
**预期**: 返回错误提示，不崩溃

### 6.2 超长输入
```bash
ask "请帮我..." # 重复 500 字
```
**预期**: 正常处理或截断，不崩溃

### 6.3 特殊字符
```bash
ask "搜索笔记 <script>alert(1)</script>"
```
**预期**: 安全处理，不执行脚本

### 6.4 并发请求
```bash
# 同时发送 3 个请求
ask "问题1" &
ask "问题2" &
ask "问题3" &
wait
```
**预期**: 每个请求独立处理，不互相干扰

### 6.5 无工具场景
```bash
ask "1+1等于几？"
```
**预期**: 直接回答，不调用工具
**验证**: 快速返回
